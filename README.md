# PromptDrawer

**50 AI prompts for solo and small-business operators** - written for people running a
business largely on their own. Version 1.0.

## What this product is

A pack of 50 written prompts. Each one is text you paste into an AI assistant you already
use (ChatGPT, Claude, Gemini, Copilot, or any similar tool). Each prompt covers a specific
job that lands on one person running a business: writing to a new enquiry, chasing an
unpaid invoice, answering a complaint, planning the week, deciding what to stop doing,
pricing a new service.

Every prompt has the same four parts:

- **When to use** - the situation it fits, so the reader can find the right one quickly.
- **The prompt** - the full text to copy, with `[SQUARE BRACKET]` placeholders.
- **Fill in** - every placeholder listed, with a sentence saying what belongs there.
- **Tip** - what to do with the output, or how to push it further.

The prompts deliberately tell the assistant to work from what the operator supplied, to ask
questions rather than invent facts, and not to add prices, deadlines, guarantees or numbers
that were not given.

## Who it is for

Someone who runs a business alone or nearly alone and has limited time: a trade, a
consultancy, a small agency, a shop, a freelancer, a one-person service business. No prior
experience with AI tools is assumed, and no other purchase is needed.

## What a buyer receives

1. `promptdrawer.md` - the whole pack as a single Markdown file: contents list, the 50
   prompts in 8 categories, each with its when-to-use line, prompt text, placeholder list
   and tip.
2. `promptdrawer.html` - the same pack as a single self-contained web page. It uses no
   external files, fonts or scripts, opens by double-clicking it in any browser, reads
   cleanly on a phone, and prints to PDF from the browser's print dialogue.

Both files stand alone. A buyer needs only one of them, and both contain all 50 prompts.

## How the files fit together

| Path | What it is |
| --- | --- |
| `prompts/*.md` | The eight category source files. **This is the single source of truth** for the prompt text - edit here, never in the generated files. |
| `tools/build_pack.py` | A dependency-free Python 3 script that reads `prompts/*.md`, validates them, and writes the two buyer files. |
| `promptdrawer.md` | Generated. The whole pack as one Markdown file. |
| `promptdrawer.html` | Generated. The whole pack as one print-ready, self-contained HTML file. |
| `index.html` | A separate marketing page that already existed in this repository. It is not part of the product pack and is not generated by the build script. |

Rebuild the two buyer files after editing anything in `prompts/`:

```bash
python3 tools/build_pack.py          # regenerate promptdrawer.md and promptdrawer.html
python3 tools/build_pack.py --check  # confirm both files still match the sources (exit 1 if not)
```

The build fails loudly rather than shipping a partial pack: prompts must be numbered 1 to 50
with no gaps or repeats, titles must be unique, and every prompt must carry all four parts.
Because both buyer files are generated from the same sources, the 50 prompts cannot drift
between them.

## What is deliberately not claimed

This section exists because the honest version is more useful than an impressive one.

- **No testimonials, no reviews, no customer counts.** There are none. This is the first
  product from this business and no one has bought it yet.
- **No results, savings or performance claims.** Statements like "these prompts will save
  you time" cannot be checked, so they are not made anywhere in the pack. What is stated is
  what is true of the product: there are 50 prompts, each is paste-ready, every placeholder
  is marked and explained, and each carries a tip.
- **Not a course, a subscription or software.** It does not connect to any account, and it
  includes no AI tool. The buyer needs their own AI assistant.
- **No invented authority.** No claims about who else uses this or where it has been
  featured.
- **No filler.** Every prompt is meant to be usable on its own, and there are no
  "write me a blog post" one-liners.

## Commercial status

Honest statement of where this stands, because it affects what anyone reading this can do:

- **The product is complete and the pack is final.** The 50 prompts exist, both buyer files
  are built from them, and the build checks pass.
- **It cannot be bought yet.** Payments onboarding for the business is not complete, so no
  amount of building makes a purchase possible today. There is no working checkout.
- **Intended price:** a low-ticket single payment, in the region of a few tens of dollars,
  to be set at launch. No price is fixed in the product files and none appears in the pack a
  buyer receives.
- **The pack itself contains no checkout or payment link.** Neither buyer file contains any
  purchase path. The separate landing page at `index.html` is pre-existing, is not generated
  by this build, and is not part of the pack.
- **Delivery is file-based.** The buyer receives the Markdown and HTML files directly - they
  are self-contained and need nothing else. No email sending, account creation or download
  service is assumed anywhere in the product.

## Reusing and editing the prompts

The prompts are plain text and belong to whoever buys this pack; they can adapt them freely.
Anyone editing this repository should change `prompts/*.md` and re-run
`python3 tools/build_pack.py`, then `--check` before publishing.
